# WarriorQR

Generador web de códigos QR normal o con logo central.

## Funciones
- QR normal.
- QR con logo.
- Personalización de color y fondo.
- Descarga en PNG y SVG.
- Diseño mobile-first para iOS, Android, tablet y escritorio.
- PWA instalable.
- Procesamiento local en el navegador.

## Uso local
Puedes abrir `index.html` directamente para probar la interfaz. Para probar la instalación PWA y el modo sin conexión, ejecuta el proyecto desde un servidor local:

```bash
python -m http.server 5500
```

Luego abre `http://localhost:5500`.

## Publicación
Puedes subir todos los archivos a GitHub Pages, Hostinger o cualquier hosting estático.
